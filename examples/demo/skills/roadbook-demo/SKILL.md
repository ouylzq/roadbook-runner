# Roadbook 入门场景

演示应用只在本机 127.0.0.1:4173 运行。执行方通过页面操作，按路书走到意图规定的停止点。

- 先按路书已记录的步骤执行。锚点或到位标志失配时，打开该步【参考】对应的 `atoms/<名称>.md`，根据页面核实变体。确认等价入口并达到到位标志后，只更新对应步骤。
- `atoms/task-list-page.md` 记录列表就绪、空状态和加载失败。 `atoms/task-create-form.md` 记录输入框、提交按钮和反馈。两个原子都可按需查阅。

裁判按验收文件重新打开任务列表，等「已保存任务」计数出现后读取。只取证，不提交表单。
