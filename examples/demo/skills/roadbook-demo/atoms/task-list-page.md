# 任务列表页

## 它长什么样

- 主标题是「任务列表」。上方是任务表单，下方是「已保存的任务」区域。
- 页面就绪后，该区域显示「已保存任务：0」或「已保存任务：1」。计数为 0 时显示「还没有任务。」。
- 从 `intent.md` 里的入口地址进入。导览页的标题是「用一份路书验证任务保存」。

## 变体

- 全新会话打开列表时，通常先显示「正在读取任务…」，随后显示计数和空列表提示。
- 从同一个浏览器会话再次打开列表时，页面读取该会话的已保存任务。任务存在时显示标题和计数。

## 已知会失败的方式

- 标题已出现，但输入框和按钮点不了 → 页面仍在读取任务 → 等计数出现后再确认表单可用。
- 页面显示「无法读取任务」和「请刷新页面重试。」 → 列表读取失败 → 刷新一次。仍失败时记录页面原文和地址。
- 页面打开后显示「还没有任务。」 → 当前列表读到了空状态 → 保留计数和空列表文案，交给当前场景的验收条件解释。
