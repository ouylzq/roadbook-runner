# 新增任务表单

## 它长什么样

- 在「任务列表」主标题下方，输入框的标签是「任务标题」，占位文案是「输入任务标题」。
- 正常版的提交按钮是「添加任务」。输入框和按钮属于同一表单，可以用输入框标签作为定位参照。
- 提交成功的页面反馈是「已添加任务」。随后输入框清空，列表出现刚提交的标题。裁判按验收文件回读保存结果。

## 变体

- 按钮改名版使用「保存任务」。输入框标签和提交反馈相同，确认按钮在同一表单内后可按原动作提交。
- 原生表单支持在输入框中按 Enter 提交。提交前先核对输入框中的完整标题，选择一次提交方式。

## 已知会失败的方式

- 只输空格后点击没有反馈 → 表单会去掉首尾空格并忽略空标题 → 重新填写场景指定的非空标题。
- 点击后按钮暂时不可用 → 保存请求还在处理 → 等待「已添加任务」或「保存请求失败，请重试。」再决定下一步，避免重复点击。
- 显示「已添加任务」，之后重新打开页面只看到空列表 → 故障版返回成功反馈但没有保存任务 → 保留两次页面的不同证据，由验收文件决定结果。
